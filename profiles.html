How to Import

Required Addons

  • EllesmereUI
  • Platynator
  • MPlusTimer
Important: Inside EllesmereUI you must disable Nameplates and Mythic+ Tools. Otherwise they will conflict with Platynator and MPlusTimer.

EllesmereUI

  • Open EllesmereUI (usually /eui).
  • Go to Profiles → Import and paste the string (or import the downloaded file).
  • After importing, use Assign Spec to assign the correct profile to each specialization.
  • There is a separate layout for each spec.

Platynator

  • Open Platynator options → Profiles → Import.
  • Paste the string or load the downloaded file.

MPlusTimer

  • Open MPlusTimer options → Profiles / Import.
  • Paste the string or load the downloaded file.
