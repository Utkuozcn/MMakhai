# MMakhai UI Profiles

Thank you for downloading my World of Warcraft UI profiles!

These profiles are designed for **1080p** resolution.

## Required Addons

- **EllesmereUI**
- **Platynator**
- **MPlusTimer**

Make sure you have the latest versions of these addons installed before importing the profiles.

## Important Setup Notes for EllesmereUI

For **Platynator** and **MPlusTimer** to work correctly, you **must disable** the following options inside EllesmereUI:

- Nameplates
- Mythic+ Tools

If these remain enabled, they will conflict with Platynator and MPlusTimer.

## How to Import

### 1. EllesmereUI Profiles
1. Open EllesmereUI (usually `/eui` or through the addon menu).
2. Go to the **Profiles** / Import section.
3. Import the corresponding file for the specialization you want (Affliction / Demonology / Destruction).
4. After importing, use the **Assign Spec** feature in EllesmereUI to assign the correct profile to each specialization.

### 2. Platynator
1. Open Platynator options.
2. Go to Profiles → Import.
3. Paste the contents of `Platynator Profile.txt`.

### 3. MPlusTimer
1. Open MPlusTimer options.
2. Go to Profiles / Import.
3. Paste the contents of `M+ Timer Profile.txt`.
